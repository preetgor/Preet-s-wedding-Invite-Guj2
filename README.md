# Preet's Wedding Invitation — Gujarati (PDF_2)

A ready-to-publish static copy of the Gujarati invitation site.
Just `index.html` + the `assets/` folder — no build step, no server needed.

## What's inside

- `index.html` — the whole site: 4 pages (Cover, Shubh Aarambh, Lagnotsav, Nimantran), book-style page turns, swipe / tap / dot / arrow-key navigation, pinch & double-tap zoom
- `assets/` — every page image in WebP (800 / 1200 / 2000 px) with JPG fallbacks, plus the link-preview thumbnail

## Publish with GitHub Pages (free)

1. Create a new **public** repository on GitHub.
2. Upload `index.html`, `README.md`, and the whole `assets` folder into the repo.
3. In the repo: **Settings → Pages → Source: "Deploy from a branch" → Branch: `main` → Folder: `/ (root)` → Save**.
4. Your site goes live at `https://YOUR-USERNAME.github.io/REPO-NAME/` in a minute or two.
